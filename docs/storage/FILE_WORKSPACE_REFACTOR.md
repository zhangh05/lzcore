# 文件工作空间重构

本轮为 A–D 全量优化，允许分批提交、推送。全部实现及验收完成前不改变 tag/Release；不部署，不运行真实模型压测。

## 数据身份与写入合同

FileRecord 表达托管原件/工作版本的身份和生命周期；Artifact 表达交付记录；ContextStore 表达知识来源；消息存储表达实际会话使用。ReferenceIndex 按 `(file_id, owner_type, owner_id, relation)` 幂等登记依赖。源码目录保留真实路径，文件空间是这些事实的投影，没有额外业务状态源。

- 上传、FileStore 导入、发布使用共享分类。未知类型保持二进制原件，不能伪装成文本。
- 消息保存/附件替换/永久删除会话协调其引用；知识来源保留原件及规范化文档身份，删除只释放对应 owner。
- 受控编辑、执行和知识文档替换沿 workspace lock 核对实际字节。被引用的旧内容保留在 `.versions`，新工作内容具有新身份；无变化不产生版本。外部未登记的覆盖不能重新标记为原历史证据。
- FileRecord 发布、Artifact 元数据/引用和受控版本封存有最小待提交意图。显式 reconcile 核对真实摘要后仅封存元数据，不重跑写入、不重放命令，也不推断原 writer 的业务结果。
- 备份恢复中断只回查现存原件和业务证据；缺失 owner 或记录时保持 unresolved，不能伪造恢复完成。
- 回收保留原件和引用；恢复核对摘要及路径冲突。永久清除保留 purged 身份及历史使用关系，以便解释原件不可用。

Candidate/Review 仍为各自唯一事实源；不恢复 Task 镜像。完整工具目录、执行能力与 canvas `item_id` 身份保持。

## Agent 文件工作流

扩展现有 `workspace.filestore`，不建立另一套工具：list/resolve、inspect/render_page、search/reindex、materialize/publish、目录组织、源码移动/打包解包、生命周期、健康/迁移/备份和显式回查。调用继续经过 ToolRuntime/ToolRuntimeClient 的身份、schema、manifest、policy、审计和项目范围。

file_id、artifact_id、filepath 只能在当前认证主体和 workspace 中解析。工作材料保留原件，返回 workspace 根相对路径及实际执行环境路径。发布读取真实受控路径，二进制 Office/图片/压缩包保留实际字节、摘要和来源；文本继续使用已有脱敏合同。

## 文件工作台

- 资料、真实工作目录、交付物、历史版本、过程资料、回收站、核对与备份分开展示。
- 服务端分页、名称/路径搜索、目录组织和排序；正文命中返回来源摘要、行号与覆盖范围。
- 多文件导入/拖放和批量删除逐项显示结果；操作先展示使用关系影响，失败项保留选择。
- 文件库可直接用于对话，无需再次上传。附件校验实际主体/workspace/lifecycle；切换会话和工作区清除待发送附件。
- 原件下载、图片/PDF、音视频、范围文本继续读取；迟到的读取结果不能覆盖另一个已选文件。
- 使用关系可以定位真实消息会话、知识 source、Artifact 和 run。run 查询使用准确身份，不依赖扫描最近若干任务。
- 真实源码目录浏览、读取和移动保留路径语义；不会自动重写源码 import 或构建配置。

## 格式能力与边界

| 格式 | 已实现 | 明确边界 |
|---|---|---|
| 文本/代码/CSV | 范围读取、原件、正文索引、CSV 行表格 | 源码修改仍沿已有执行与编辑权限 |
| 图片/SVG | 原件、支持格式浏览器预览、真实视觉证据；Pillow 可解码图片可转换为 PNG 证据 | SVG 源码/绘图保持；图片转码不冒充原图，不保证所有浏览器解码格式 |
| XLSX | 工作表、单元格坐标、公式与缓存值分别读取 | 没有缓存值明确显示；不声称重新计算公式或渲染完整图表 |
| DOCX | 正文段落/表格真实顺序与样式、已有内嵌图片提取 | 结构预览不等于完整排版 |
| PPTX | 逐页文本、表格、备注、实际对象位置 | 不声称完整视觉渲染或理解所有图片 |
| PDF | 原件预览、按页文字/覆盖情况、真实页图与证据 | OCR 为显式操作，需已安装 Tesseract；不消耗模型额度 |
| ZIP/TAR | 成员、真实打包、授权目录内独占解包 | 拒绝路径逃逸、链接及目录/文件冲突；不保证 7z 等处理器存在 |
| 音视频/旧 Office/未知类型 | 真实保存、下载、发布；适用音视频浏览器播放 | 播放取决于浏览器解码；没有通用编辑、转录或旧 Office 转换承诺 |

## 长期治理

列表使用与查询/workspace 绑定的稳定游标；引用批量投影。SQLite 正文索引只保存可重建投影，活动文本自动同步，Office/PDF 解析正文显式重建，不调用模型或 embedding。

健康核对分别声明原件存在性、大小、可选全文摘要、引用目标以及实际消息/Artifact/知识 owner；其他 owner 类型列为未检查。历史迁移只补充由 owner 原记录证明的关系，保留迁移前备份；不自动按同 hash 删除对象或重新解释历史字节。

文件域 ZIP 备份包含 FileRecord、可用原件、引用、Artifact、相关会话及知识证据。导出与恢复以流式 payload 处理。恢复预览校验主体/workspace、身份、摘要和目标冲突；不覆盖已有冲突内容，同一使用关系不重复恢复。不包含 Provider 配置、密钥、未注册源码树或运行中的作业；无法恢复的原件单独报告。

## 验证记录

- 离线真实 payload 流程覆盖多格式导入、Office/ZIP 发布、图片证据、分页/路径、owner 生命周期、恢复冲突和元数据故障回查。
- 一万真实临时文件、三万引用：20 次列表 p95 212ms；已建索引正文搜索连同列表投影 p95 252ms；首次文本索引与搜索 3.06s。200 项分页遍历一万身份无遗漏/重复（macOS arm64）。首次索引成本与已建索引查询分开报告。
- 浏览器验证已有文件复用、会话隔离、Office 结构、扫描件页图和窄窗口；CI 增加实际接口文件组织与回收恢复场景。
- Windows 工作流增加两套 Python 原生文件流程测试，以及便携/安装版真实应用中的中文名称/目录、原件字节恢复和备份预览。

Windows 工作流和远端 CI 需实际完成后才能作为验收证据。上述工程验证不等于真实大型模型业务验收，历史 NOC/RTS 仍未通过。
