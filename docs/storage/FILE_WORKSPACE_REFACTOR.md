# 文件工作空间重构

本轮授权为 A–D 全量优化；分批提交、推送。全部优化完成并验收之前不改变 tag/Release，不部署，不运行真实模型压测。

## 已实现的基础合同

- 上传、FileStore 导入共用文件类型分类；未知类型保留为 binary，不伪装成文本。
- 消息附件引用按消息身份幂等写入，附件替换和永久删除会话处理引用。
- 知识上传保留原件，解析 source 显式引用原 FileRecord。知识删除释放本 owner 引用，不清除被其他 owner 使用的文件。
- 文件工具和执行入口沿既有 workspace lock 核对托管内容变更。被引用的旧字节保留在实际历史版本，新工作内容有新的 FileRecord；无变化不创建版本。提交不明时不自动重放。
- 文件 API 普通删除使用 soft_deleted；永久清除使用 purged 身份记录，历史 owner 可以查询明确的原件不可用状态；索引整理不丢弃回收和 purged 身份。
- 回收文件可恢复，实际 payload 摘要和路径冲突必须核对。
- 文件列表的引用一次读取分组，文本预览范围可继续读取；文件下载和图片/PDF 预览沿认证工作区。
- 保存回答不再从前端额外上传独立副本。
