# 后端接入合同

Flask 路由在 backend/main.py 和 backend/api/ 注册；完整公开面见 [API](../API.md)。工具 handler 不是公开 API，也不能从路由绕过治理执行。

## 请求

工作区字段统一从 path/query/JSON/multipart 解析。多个来源必须相同，否则 workspace_id_conflict；不得给缺失工作区伪造 default。资源权限按当前认证主体验证。WebSocket 每次操作仍检查当前账号和范围，不能仅信握手时的角色。

## 响应与恢复

AgentResult 是任务结果投影；任务、工具尝试和未知写入分别呈现。应用错误返回稳定标识及安全校验信息，不返回堆栈或密钥。HTTP 状态不证明副作用是否发生。

回合正文帧先持久化再发送；控制错误不进入正文 reducer 当作模型失败。resume 只补缺失事件，不执行消息。Agent 会话 SSE 未接入实时生产者；其他 SSE 继续按各自路由合同使用。

## 修改路由

同步路由、调用端、API 文档、认证/范围/schema 测试及代理配置。校验合法输入、冲突工作区、旧身份、重复请求、终态和未知写入。只读排障查询只证明已保存数据，不能证明客户端已收到。
