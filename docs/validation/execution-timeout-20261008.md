真实 RTS 单轮中，模型为依赖安装指定 `timeout=180`，但生产入口和节点调度上限均固定为 120 秒；外层先取消，隔离环境关闭。生成工程另有模块导出不匹配、未安装依赖和零测试用例，不能把这些应用问题归结为同一个框架原因，完整 RTS 验收仍未通过。
