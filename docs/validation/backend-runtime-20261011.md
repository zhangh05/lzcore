## 验证结果

基线全量 harness：2403 通过、11 跳过，69.95 秒。修复和整理后：2364 通过、11 跳过，53.29 秒，同一台 macOS 主机。用例净减少 39 个；耗时是本轮观测，不是跨平台性能承诺。
