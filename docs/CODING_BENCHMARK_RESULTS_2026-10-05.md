# 架构修复与压力验证：2026-10-05

本轮修复模型窗口续接、工程系统隔离、独立验收、模块职责和 Coding Team。使用真实失败推动修复，保留失败记录；不把 Agent 最终文案、子任务完成或应用启动等同于交付成功。本轮只同步 GitHub 和 Release，不部署服务器。

## 已实现的架构

- 不可变的完整上下文归档与新模型窗口续接；主体/工作区/会话身份、父归档和 SHA256 校验。未知写入仍只回查，不重放。原始约束、工具证据、原生协议和任务状态可检索。
- 工程仅挂载到非 root、只读根文件系统的容器。Shell/Python 共用工程执行适配器及可写工程默认目录；框架、Evaluator、宿主 HOME、凭据、Docker Socket 不可见。仅依赖 registry 可经独立 TLS broker 出站，迟到调用不能回退宿主。
- 实现、前端、QA 角色共享完整受治理工具目录；父任务和会话身份来自服务端。独立工程副本、显式源码/生成物合同、准确候选 QA、真实命令证据、冲突安全整合与可恢复事务。
- 强隔离工程的源码所有权属于实现分支；协调者和 QA 使用只读源码挂载，文件 API 同步拒绝绕过；声明构建目录、依赖目录和 /tmp 保持可写。转换时有活动命令则拒绝；重启失败关闭环境。容器监听端口与工作区浏览器转发端口分离，源码不用因分支切换修改。
- 实现依赖消费已整合发布，QA 对其候选消费成功的 changes_ready/validated；同父任务/会话的已授权等待任务在依赖转换后自动调度。依赖失败明确终止，跨进程启动领取与不可逆终态阻止重复运行或取消结果被旧状态覆盖。
- 服务端精确绑定验证命令；协调者/QA 的测试与构建使用一次性工程快照容器，允许标准构建删除/重建输出根。停掉后代、确认清理且源码摘要不变后才回传声明的产物；额外命令仍为只读，源码变化或输出符号链接拒绝。
- 委派任务生命周期与请求等待分离，同步请求最多等待 15 秒；任务句柄持久化，取消跨进程可见。压力任务结束核验全部委派分支及容器清理。
- 原始模型提案、执行交互和发送协议分离。统一投影处理重复调用抑制、编号重排和批量编译，保留原生思考块/签名；持久化恢复保留空调用列表。厂商拒绝请求只记录内容无关的请求结构诊断，不盲目重试通用 400。
- 目录、策略和运行时共用 schema 执行合同；独立无 action 的等待保持只读语义，声明时长预留返回时间并保留调用方时限。实际 30 秒等待通过，未知写入继续回查。
- 发布 journal 使用持久化工作区顺序；验收每次独立 QA，从完整初始基线按 before/after 链重建最终源码树；核对未改动文件和不存在的路径，拒绝未评审新增文件，拒绝未评审改写和伪造顺序。
- 生成 RTS 引擎及其编译器运行在另一个无网络的只读 QA 容器；可信宿主验收器持有随机场景与断言，只接收有时间/大小上限的 JSON RPC。生成代码无法替换宿主断言。

原生思考块和签名的保存要求见 [Claude 官方协议说明](https://platform.claude.com/docs/en/build-with-claude/thinking)。本轮真实 Provider 是 MiniMax-M3；不能据此声称全部厂商已经完成真实长任务验证。

## 独立验收覆盖与边界

NOC 新增随机接口计数器/速率、noBuffers/CRC/低利用率 HighPPS、告警去重/确认/恢复、实际依赖根因、配置写入/行 Diff/回滚/审计、viewer 服务端权限和压力规模。RTS 新增三 Seed 的真实伤害/死亡、200 单位群移、队列与性能、保存后 RNG/AI/命令确定性以及 300 秒引用清理。实现者看不到验收器，断言不在生成应用进程里。

这些命名检查尚不能证明完整 NOC 或 RTS 成功。当前生成的两款大型应用没有完整通过；前置启动/构建失败时，后续业务命题仍未得到有效验证。全部 RCA 场景、UI 重连、进程重启、全部 choke/编队/AI 经营/科技/胜败等仍须逐项实测。报告保持 `full_benchmark_acceptance=NOT VERIFIED`。不降低业务合同，不用 Coding Agent 自己的测试作为独立验收。
