## 已实现的框架修复

- 精确源路径创建与 FileStore 附件分开；原子创建、存在即拒绝覆盖、主/子 Agent 共用治理合同。
- 当前外部观测默认重读，只有显式纯计算合同允许复用；失败恢复使用状态修订。
- 浏览器按主体/工作区/会话隔离，服务器只授予精确本地预览 origin；真实控制台和网络观测有界保存。
- 快照提供控件可操作状态，未发送的禁用/隐藏/歧义点击返回明确原因；相同批次错误先交回模型，按恢复轮次计数。
- 合法原生推理块保留；非法 tool input 不继续污染 Anthropic 反馈请求；具体 Provider 错误保留脱敏诊断。
