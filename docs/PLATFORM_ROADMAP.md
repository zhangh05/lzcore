# 演进方向与验收要求

本页记录方向，不将未完成规划表述为功能。当前可用面以源码、API 和发行附件为准。

基础包括统一运行时与工具治理、工作区/制品/知识/记忆、作业与 DAG、签名扩展包、网络运维和独立绘图、Windows 两种桌面发行方式及 Compose 部署。

后续优先检查：

1. 行业扩展能否完成对象生命周期、资源授权、工具与 UI 闭环。
2. 驱动的事实模板、版本匹配和写后验证是否减少模型猜测。
3. 多节点存储、队列、文件锁和故障演练是否支持目标部署方式。
4. API/扩展兼容、更新回退与可观测性是否有发布验证。
5. 同任务、同模型的 Agent/画板评测能否量化首轮正确率、修正次数、覆盖和耗时。

每项实现前确定数据、权限、失败与未知写入语义、删除/恢复及实际验收环境。文档和提示词的简化只有通过行为检查和样本评估才能说明效果。
