# 联智中枢整体审查与修复记录

日期：2026-10-01。基线：`main` / `5c8a6a8`，版本 `3.2.4`。按本轮用户要求，仅提交和推送修复，不部署服务器或重启现有服务。

## 审查范围

检查了认证与工作区隔离、模型编排、工具治理网关、外部写入与审批恢复、作业、存储、扩展、网络设备与拓扑、前端认证及事件传输，以及构建、测试和部署配置。采用代码检查、调用链追踪、回归用例和仓库原有 Chromium E2E。Code Review 插件当前暴露的接口用于 PR CI 检查，本轮没有借该接口执行本地源码审查。

此记录描述本轮确认并修复的问题，不代表每个源码分支、真实设备和生产环境都已验证。

## 已修复的问题

| 级别 | 触发与原行为 | 修复位置与结果 |
| --- | --- | --- |
| P1 | 使用可解析的连接 ID 后缀时，设备工具能执行，审批却因与完整 ID 比较不匹配而跳过。 | `extensions/approval/service.py`：先解析 canonical ID，再核对当前 Skill 和已选连接范围。 |
| P1 | 选择 Skill 后开启审批，运行时仍读取选择时的关闭快照，配置调用绕过审批；反向切换也会保留旧要求。 | 同上：调用时读取已发布 Skill 的当前开关和范围。 |
| P1 | 拦截器发现或审批钩子异常被吞掉，后续真实写入照常执行。 | `core/runtime_engine/execution_interceptors.py`、`query_loop.py`：返回未执行的结构化错误，禁止继续调用 handler，不泄露原始异常。 |
| P2 | 决策请求可通过 `decided_by` 伪造审批记录中的身份。 | `extensions/approval/backend.py`：身份来自服务端认证主体；本地无认证主体时使用 `user`。 |
| P2 | 拓扑调用在编排层和执行网关中被整体豁免 schema 错误，错误参数可以进入 handler。 | `core/tools/executor.py`、`core/runtime_engine/query_loop.py`：删除豁免；合法自然别名、额外字段和字符串版本继续支持。 |
| P2 | 编排层只检查数组中的字符串或 `oneOf` 元素，普通对象数组的错误元素仍被当成合法计划。 | `core/runtime_engine/semantic_validator.py`：对所有非空元素 schema 共用执行网关的递归校验。 |
| P2 | 拓扑成功 patch 的输出没有 `action`，绘图完成门禁无法识别真实成功，可能要求重复绘制。 | `extensions/network_operations/backend.py`：成功结果返回实际 `read` / `patch`。 |
| P2 | 未填 action 且只删除分组或图元时，被推断为读取，返回成功但未删除。 | 编排层和拓扑工具均补全删除字段判断；测试核对实际保存结果和其他节点保留。 |
| P2 | schema 声明的 `title` / `summary` / `comment` 被接受，却不保存到标题与描述。 | 拓扑工具映射到 canonical 字段；显式 canonical 值优先，清空描述也可识别为修改。 |
| P2 | fetch SSE 的 CRLF 跨网络分片时被转换为额外空行，同一事件错误拆分并丢失事件名或完整内容。 | `frontend/src/api/sse.ts`：跨分片跟踪 CR，保留命名事件、多行内容和事件 ID。 |
| P2 | Cookie 登录部署明确禁用本地令牌后，每次 API 调用仍重新请求 `/api/local-token`；并发调用也各自探测。 | `frontend/src/api/client.ts`：共享在途请求，缓存明确的 `local_token_unused`；临时故障仍可重试。 |

保留已有产品语义：审批仍为 Skill 的可选开关；设备账号决定命令最终权限；外部写入未知不自动重放；拓扑增量 patch 保留自动版本对齐；直接保存仍检测版本冲突；硬删除语义未变。

## 验证结果

- 修复前新增用例复现了审批与拓扑的 13 个失败场景；SSE 和令牌探测的新增用例也先复现失败，再通过修复。
- 最终 `.venv/bin/pytest harness/ -q --tb=short`：**1670 passed, 8 skipped**。较基线增加 15 个后端用例。
- 最终 `npm --prefix frontend test -- --run`：**64 files / 318 passed**。较基线增加 4 个前端用例。
- `npm --prefix frontend run e2e`：**33 passed**；使用临时存储和独立服务，包含登录、工作区隔离、工作台和拓扑编辑等流程。
- `npm --prefix frontend run build`：通过 TypeScript 编译和生产构建。
- Ruff `E9,F821,F811`、文档一致性、扩展兼容性、运行时配置检查、平台评估、CSS tokens、命名契约和 `git diff --check`：通过。
