# SVG 文件生成：Agent 实测与恢复修复

用户原始请求：`创建一个HTML，内容是SVG绘制一个鹈鹕骑自行车的2D动画`。
请求 SHA-256：`d1d1d34e919cf708a16b27ba1b37e93d2c69b5c9f9a66b34297c8f67827fdeda`。

测试使用真实 custom / Ling-3.0-flash / openai_compatible 服务，不使用预先编写的应用或旧样例。HTTP 测试创建独立工作区和会话，每条请求只提交一次；未知结果回查作业，不重放。原始状态保留在测试工作区，归档只收集白名单字段，不含凭据或私有推理文本。详见 [结构化证据](SVG_AGENT_EVIDENCE_2026-10-06.json)。

## 已确认的框架问题

1. HTTP 入口此前没有将持久回合的取消检查传给实际 Agent，也没有将实际阶段事件投影回作业。取消登记可以成功，模型请求仍继续，界面阶段停在理解任务。修复复用现有 session job、MainAgentRuntimeControl 和 StreamEmitter；终态或请求身份变化后取消旧执行，过期事件不能更新新请求。
2. Provider 已完成有界空响应重试和候选回退后，QueryLoop 把 provider_empty_response 当作可持续恢复的通用故障，在生产无限回合设置下反复请求。现在归一化为 llm_empty_response，明确失败并保留证据，不把工具成功或空响应当成目标完成。此内核路径由 HTTP 和 WebSocket 共用；本报告没有采集用户 Windows 会话的原始运行日志，不能据此断言其全部故障原因相同。
3. 兼容协议 SSE 的工具参数经过 JSON 解码后，原生协议块未保留原始工具提案，截断内容只剩无效 JSON 标记。现在保存原始提案；给模型续接时仍显式屏蔽未执行调用，部分文件不会被写入。续接提示说明输出预算以及使用已发布文件工具分步组装完整制品；本次 4096 实测没有遵循该分步建议，不宣称提示词优化已让任务成功。
4. harness 的旧 Provider 备份恢复 fixture 虽已有隔离配置目录，仍删除再恢复仓库真实 config/providers。并行回归曾使一轮真实运行短暂读到本地缺失凭据。fixture 现在只操作 LZCORE_CONFIG_DIR 下的测试配置，回归验证真实目录文件及 inode 不变。受干扰轮次保留为无效测试，不归因于服务商认证或模型能力。

## 实际运行结果

所有轮次保持完整原始请求。基础提交为 b5bc5e133e0cefc5a80b1b343f3e8c93ef9901a1；修复过程中未提交的源码差异指纹记录在证据中。

| 轮次 | 入口 / 输出上限 | 结果 | 实际业务产出 |
| --- | --- | --- | --- |
| HTTP 1 | 生产入口 / 4096 | 卡在截断后重复空响应；取消登记未停执行，最终完整重启停止测试线程 | 无 HTML、无工具执行 |
| HTTP 2 | 修复后的生产入口 / 4096 | 62.09 秒，明确 llm_empty_response | 无 HTML、无工具执行 |

| HTTP 3 | 修复中的生产入口 / 4096 | 24.60 秒，本地配置被旧 fixture 短暂移除；测试环境干扰，不能作为模型能力结果 | 无 HTML、无工具执行 |

Native 比较使用与产品相同的 AgentApp、模型协议适配和 ToolRuntime，只有文件/记忆/报告目录及输出预算在独立进程隔离。它不是生产 HTTP 8192 验收，也不是严格 Docker Coding Team 压测。宿主凭据没有复制到工程容器。生产配置仍为 4096，没有自动扩大用户设置。

8192 轮次首个完整文件工具请求消耗 7772 个输出 token（含模型推理与工具参数），超过 4096。这个样本说明该次整文件提案需要更高输出预算；不能推出所有 SVG 请求至少需要 8192，也不能用它掩盖 4096 重复失败。

## 独立浏览器核验

文件由真实 Agent 创建，测试者没有修改应用源码。交付副本与 Agent 输出逐字节一致：16480 字节，SHA-256 为 `f4b8e6a2e3973f71c150b1de0220d7dba49a2b116cd475d349160e90a0ff0808`。

真实 Chromium 通过本地 HTTP 打开文件，确认：

- 1 个内联 SVG，viewBox 为 0 0 800 500，13 个运行中的 CSS 动画。
- 两个车轮、踏板、身体、翅膀和整体倾斜的计算变换在相隔 370 ms 的采样间变化；不是静态截图冒充动画。
- 无页面脚本异常、外部资源依赖、外部请求、重复 SVG ID 或未解析渐变引用。首次页面打开的 favicon 404 不属于应用脚本错误。
- 375 px 宽度时文档宽度为 375 px，SVG 为 375 × 234.375 px，完整画面可见；桌面和手机截图分别检查。

视觉质量有限：鸟的嘴部比例较短，鹈鹕特征不突出；腿脚与旋转踏板没有严格同步。只确认文件产出、SVG 动画运行和基本画面，不把它描述为高质量自然骑行动画。生产 4096 下的业务目标仍未完成。
